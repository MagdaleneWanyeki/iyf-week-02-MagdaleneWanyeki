## Project Description

This project is part of my IYF Season 12 Week 1 Web Foundations training.

During this week, I learned the basics of web development and created my first multi-page portfolio website using HTML. The project gave me an opportunity to practise writing HTML code, organizing webpage content, creating links and working with forms.

I also explored website accessibility and learned how to make webpages easier for different users to access and understand.

The website contains four pages: Home, About, Projects and Contact.

## Technologies Used

- HTML5 – Used to create and structure the webpages.
- GitHub – Used to store and manage my code.
- Chrome DevTools – Used to inspect webpage elements.
- Lighthouse – Used to check accessibility.
- WAVE Accessibility Tool – Used to identify accessibility issues.
- GitHub Pages – Used to publish my website.

## Features

- Home page with my name, tagline and introduction.
- About page with background information, skills and education/experience timeline.
- Projects page displaying at least three project examples.
- Contact page containing a contact form.
- Contact form with name, email, phone, subject and message fields.
- Newsletter subscription checkbox.
- Form validation using HTML attributes.
- Navigation links connecting all four pages.
- Highlighted navigation link showing the current page.
- Images with alternative text.
- Proper heading structure.
- Descriptive links for better accessibility.
- Social media links.
- Location and timezone information.

## How to Run

1. Open the project folder in Visual Studio Code.
2. Locate the `index.html` file.
3. Right-click the file and select **Open with Live Server**.
4. The website will open in your browser.

Alternatively, open `index.html` directly in your web browser.

## Lessons Learned

Working on this project helped me understand the basics of creating websites using HTML.

Some of the things I learned include:

- How to create a basic HTML document.
- How to use headings, paragraphs, lists and links.
- How to add images to a webpage.
- How to connect different HTML pages using navigation links.
- How to create forms and use different input types.
- How to use semantic HTML elements to organize webpage content.
- Why website accessibility is important.
- How to add alternative text to images.
- How to organize headings and write descriptive links.
- How to use Lighthouse and WAVE to check accessibility.
- How to use Git and GitHub to manage my work.
- How to publish a website using GitHub Pages.

## Challenges Faced

While working on the project, I experienced a few challenges.

- **HTML structure:** At first, understanding how to organize webpage elements was challenging. Practising with different HTML tags helped me understand how they work.

- **Website accessibility:** I learned that missing image descriptions and unclear links can affect how people use a website. I used Lighthouse and WAVE to check for these issues.

- **Navigation:** Connecting the four pages required me to pay attention to file names and link paths. I tested the links to make sure they worked correctly.

- **Contact forms:** Learning how to use labels, input fields, dropdowns and validation attributes took some practice.

- **Project organization:** I also learned how important it is to keep HTML files and images properly organized in folders.

Overall, these challenges helped me practise more and become more familiar with HTML and website development.
